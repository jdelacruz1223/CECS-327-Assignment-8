# CECS-327-Assignment-8

## Overview
Our system follows a distributed client-server architecture integrated with two Google Cloud and Neon database environments. The TCP client handles user input and accepts only the required queries. The TCP Server processes queries using data from the Neon PostgreSQL databases (House 1 and House 2). Sensor data is generated by Dataniz and streamed into these databases using a forward-only replication model.
