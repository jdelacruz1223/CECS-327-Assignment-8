# CECS-327-Assignment-8

## Overview
Our system follows a distributed client-server architecture integrated with two Google Cloud and Neon database environments. The TCP client handles user input and accepts only the required queries. The TCP Server processes queries using data from the Neon PostgreSQL databases (House 1 and House 2). Sensor data is generated by Dataniz and streamed into these databases using a forward-only replication model.

## System Architecture
The system consists of:
1. TCP Client: Python interface for selecting and sending IoT data queries
2. TCP Server: Multi-connection middleware that interfaces with two separate Neon PostgreSQL databases
3. Data Sources: Virtual IoT devices (Fridge, Dishwasher) generating data through DataNiz

## Implementation Details
1. Data Connection and Retrieval
2. Distributed Query Processing
3. Query Completeness Determination
4. DataNiz Metadata & Sharing
